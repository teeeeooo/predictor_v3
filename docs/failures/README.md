# Failure Records

Use this directory for repeated or non-obvious failed approaches whose lesson is likely to prevent future wasted work or regression.

A useful record states:

- attempted approach;
- observed failure;
- cause or best-supported explanation;
- do-not-repeat guidance;
- current relevance; and
- owner/evidence pointers.

A regression test is normally the primary guard. Add a failure record only when the lesson is not obvious from the test or current source.
