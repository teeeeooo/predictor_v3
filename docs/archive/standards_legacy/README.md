# Standards Legacy Notes

이 폴더는 canonical standard 문서로 흡수된 과거 구현/검토 노트 원본을 보존한다.

Active 기준 문서는 각 standard 폴더의 `*_notes.md`, `*_dev_notes.md`, `*_design_notes.md`, `*_glossary.md`다. 이 폴더의 파일은 과거 PDF review 범위, official calculator 비교값, 구현 메모의 원형을 확인해야 할 때만 historical source로 참조한다.
