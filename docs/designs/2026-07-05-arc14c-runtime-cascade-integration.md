# Arc 14C - Runtime Cascade Integration

## Purpose

Connect the runtime `mapping.json` sections generated by Data Mapping Manager
to Predict dropdown and autofill behavior without changing Data Mapping CRUD,
schema contracts, fixtures, ML, model, or calculator logic.

## Current Runtime Path

Predict uses these owners:

- `PredictMappingRepository` loads and caches `mapping.json`.
- `DropdownOptionAdapter` exposes mapping-backed base dropdown options to the
  table delegate.
- `InputEditController` receives row edit events and calls
  `core.mapping.autofill.build_autofill_updates`.
- `core.mapping.autofill` owns simple mapping autofill and ODU Cond Specs
  cascade decisions without Qt imports.
- `PredictWorkspace` only wires the adapter/controller results into the table
  and status label.

The current path already has a partial ODU cascade skeleton, but it needs
hardening around base fin/pi/row options, invalid section shapes, stale
row-specific options, and explicit missing mapping behavior.

## Schema Fields

Relevant `config/predict/schema.csv` fields:

| Column key | Runtime role | Mapping section / attribute |
| --- | --- | --- |
| `idu` | base dropdown and simple autofill trigger | `idu` |
| `evap_index` | base dropdown and simple autofill trigger | `evap_index` |
| `odu` | base dropdown, simple autofill trigger, cascade trigger | `odu` |
| `fin_type` | dependent dropdown | `odu_cascade.Available_Fins`, base `fin_type` |
| `pi` | dependent dropdown | `odu_cascade.Available_Pis`, base `pi` |
| `row` | dependent dropdown | `odu_cascade.Available_Rows`, base `row` |
| `compressor` | base dropdown and simple autofill trigger | `compressor` |
| `ref_type` | base dropdown only | `ref_type` |
| `exp_type` | base dropdown only | `exp_type` |
| `cond_area` | composite autofill target | `cond_specs[ODU Fin Pi Row].Cond Area` |
| `cond_volume` | composite autofill target | `cond_specs[ODU Fin Pi Row].Cond Volume` |

No `config/predict/schema.csv` change is required for Arc 14C.

## Design Contract

- `mapping.json` remains the runtime SSOT.
- Runtime-owned ODU Cond Specs sections are `odu_cascade`, `cond_specs`,
  `fin_type`, `pi`, and `row`.
- Composite `cond_specs` lookup key is built directly from selected values:
  `"{ODU} {Fin Type} {Pi} {Row}"`.
- ODU names are not parsed or split; the selected ODU string is used as-is.
- Before ODU selection, `fin_type`, `pi`, and `row` use their base sections
  when available.
- After ODU selection, row-specific options come from
  `odu_cascade[ODU].Available_Fins/Pis/Rows`.
- When ODU + Fin Type + Pi + Row match a `cond_specs` row, Cond Area and Cond
  Volume are autofilled.
- When a complete combination does not match, Cond Area and Cond Volume are
  blanked so stale values do not remain.
- Missing or invalid runtime sections produce empty options or no autofill; no
  hard-coded fallback options are created.

## Excluded Scope

- Data Mapping CRUD changes.
- Import, CSV import/export contracts, or XLSX export.
- Predict Schema Catalog or Feature Catalog changes.
- Fixture, golden expected, ML, model, or calculator changes.
- UI polish beyond existing status paths.

## Implementation Result

Arc 14C preserved the owner split:

- Core owns cascade lookup and invalid-shape defensive behavior.
- Predict adapter/controller own base-vs-row-specific option coordination and
  row edit side effects.
- Predict workspace remains a display/input surface and does not parse raw
  mapping JSON.

Final behavior:

- ODU selection narrows Fin Type, Pi, and Row with `odu_cascade`.
- Blank ODU exposes base `fin_type`, `pi`, and `row` sections when available.
- Complete ODU + Fin Type + Pi + Row combinations fill Cond Area and Cond
  Volume through `cond_specs`.
- Unmatched or invalid `cond_specs` clears Cond Area and Cond Volume.
- Missing `ref_type`/`exp_type` sections return empty options and no fallback.
- Missing or invalid ODU cascade sections return empty row-specific options
  without crashing.
