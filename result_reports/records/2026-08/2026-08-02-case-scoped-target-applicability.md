# Change Reason

Predict treated cooling capacity as globally required and executed the full
runtime Target set for every runnable row. That blocked heating-only rows and
turned valid subset success into fabricated missing-output failures.

heating-only, or eligible Ref Qty-only subset before preprocessing. Requests keep
runtime descriptors for exact inference; execution context pins their ordered
stable identities. Canonical acceptance, stored/historical validation, migration,
aggregate status, EER/COP, Result Review, and clipboard consume that same
evidence. The full runtime registry and Active compatibility remain unchanged.
